# 🎵 음악 수행평가 관리

음악 선생님 한 분이 전교생(500~1,000명)의 수행평가를 관리하기 위한 웹앱입니다.
태블릿·휴대폰·PC 어디서나 쓸 수 있고, **인터넷이 끊겨도 동작**합니다.

> 🔒 **학생 정보는 이 기기(브라우저) 안에만 저장되며, 어디로도 전송되지 않습니다.**
> 앱은 처음 열 때 화면 파일만 내려받고, 그 뒤로는 외부와 통신하지 않습니다.
> 그래서 **백업은 선생님이 직접** 해 두셔야 합니다 (아래 "백업" 참고).

---

> ❓ **사용법은 앱 안에 있습니다.** 화면마다 오른쪽 위 **❓ 사용법** 버튼을 누르면 실제 화면 그림이 자동으로 넘어가며 설명합니다.
> 전체 모음은 **설정 → 사용법 모음**에 있어요. 처음이라면 **🎓 연습 모드**에서 가짜 학생으로 먼저 눌러 보세요.

## 1. 처음 시작하기
앱 주소를 열면 사용법 그림이 먼저 나오고, 이어서 **처음 설정** 화면이 나옵니다.

> 🎓 **먼저 연습해 보기**: 처음 설정 화면의 보라색 상자(또는 설정 → 연습 모드)를 누르면 가짜 학생·점수가 들어 있는
> 연습 공간이 열립니다. 무엇을 눌러도 진짜 데이터는 바뀌지 않고, [연습 끝내기]를 누르면 연습한 내용은 사라집니다.

순서대로 따라가세요.

1. **학년도·학기** 선택
2. **학급 만들기**: "중학교 / 1학년 / 반 수 12 / 반당 25명"처럼 입력하고 [학급 만들기]. 학년마다 반복합니다.
3. **학생 명단** (선택): 엑셀에서 `학년, 반, 번호, 이름` 표를 복사해 붙여넣거나 파일을 올립니다.
   이름이 없어도 됩니다. 번호만으로 모든 기능을 쓸 수 있어요.
4. **규정 확인**: 기본값을 보여 줍니다. 우리 학교 규정과 맞는지 확인하고 체크합니다.
5. **평가 계획 만들기**로 이동합니다.

처음에 "데이터는 이 기기에만 저장됩니다" 안내가 한 번 나옵니다.

## 2. 홈 화면에 추가하기 (앱처럼 쓰기)
홈 화면에 추가하면 아이콘을 눌러 바로 열 수 있고, 인터넷이 없어도 열립니다.

- **아이패드·아이폰 (사파리)**: 아래쪽(또는 위쪽) **공유 버튼(□↑)** → **홈 화면에 추가** → 추가
- **안드로이드 태블릿·휴대폰 (크롬)**: 오른쪽 위 **⋮** → **홈 화면에 추가** 또는 **앱 설치**
- **PC (크롬·엣지)**: 주소창 오른쪽의 **설치 아이콘(⊕)** → 설치

⚠ 아이폰·아이패드는 **사파리에서 연 데이터**와 **홈 화면 앱의 데이터**가 서로 다릅니다.
한 가지 방법으로만 쓰세요 (홈 화면 앱 추천).

## 3. 매일 쓰는 기능
아래쪽 탭: **처음 화면 / 점수 입력 / 메모 / 성적·세특 / 설정**

처음 화면의 큰 버튼 4개(점수 매기기 · 메모 쓰기 · 성적·엑셀 · 세특 쓰기)로 바로 갈 수도 있습니다.

### 보기 설정 (설정 화면)
- **글자 크게 보기**: 화면 글자와 버튼을 크게
- **자세히 모드**: 규정 설정, 변경 이력, 항목 보관함, 엑셀 열 순서, 세특 수준 구간 같은 세부 기능을 보여 줍니다. 평소에는 꺼 두셔도 됩니다.

### 점수 입력 (실기 평가 중)
1. **점수 입력** 탭 → 학급 → 평가 항목
2. **순서 모드**: 학생이 한 명씩 크게 나옵니다. 점수(또는 상/중/하)를 누르면 **자동 저장되고 다음 학생**으로 넘어갑니다.
3. **표 모드**: 반 전체 목록에서 아무 학생이나 눌러 고칩니다. [미입력], [재평가 대기]만 골라 볼 수 있어요.
4. **결시·미제출**: 큰 버튼(인정 결석 / 미인정 결석 / 미제출 / 나중에 다시 평가) 중 하나를 고르면 **규정 설정대로 자동 처리**됩니다. 인정 결석은 질병·경조사 등 사유를 하나 더 고릅니다.
   - "재평가 우선"인 사유는 **재평가 대기**가 되고, 나중에 재평가 점수를 넣거나 [재평가 불가]를 누르면 인정점 등이 적용됩니다.
5. 잘못 눌렀으면 **↶ 되돌리기** (다른 화면에 다녀와도 됩니다). 저장 버튼은 없습니다. 누르는 즉시 저장돼요.
6. 학생 카드의 **📝 메모**로 그 학생의 관찰 메모를 바로 남길 수 있습니다.

### 관찰 메모
- 어느 화면에서든 오른쪽 아래 **📝 버튼** → 학급·번호 → 태그 → 한 줄 → 저장
- **메모** 탭에서 학생별로 모아 보고, 태그·기간으로 걸러 볼 수 있습니다.
- 태그와 자주 쓰는 문구는 **설정 → 규정 설정 → 목록 편집**에서 바꿉니다.

### 이름 가리기
수업 중 화면을 TV에 띄울 때 오른쪽 위 **이름 가리기**를 켜면 모든 화면에서 번호만 보입니다.

### 대시보드
반 × 평가 항목 진행 현황(✔ 완료 / ◐ 진행중 / ○ 미시작), 재평가 대기, 예정 기간이 지난 항목,
세특 진행률이 한눈에 보입니다. 칸을 누르면 그 반 점수 입력으로 바로 갑니다.

## 4. 새 학기 평가 계획 만드는 법
평가 항목은 앱에 정해져 있지 않습니다. 선생님이 직접 만듭니다.

1. **설정 → 학기 추가**: 새 학년도·학기를 만들면 지금 학급·학생 명단을 복사할 수 있습니다 (점수·메모는 복사 안 됨).
   학생 명단이 바뀌었으면 **설정 → 학급·학생 관리 → 명단 가져오기**로 새 명단을 넣으세요.
2. **설정 → 평가 계획**
   - **📥 지난 학기·다른 학년 계획 불러오기**: 지난 학기를 고르고 [선택한 계획 불러오기] → 바뀐 부분만 고칩니다.
     (원본은 바뀌지 않고, 점수는 복사되지 않으며, 평가 기간은 비워집니다.)
   - 또는 **＋ 새 평가 계획** → 학교급·학년·과목 → **＋ 새 항목**
3. 항목마다 **① 이름 ② 점수로/상·중·하로 ③ 만점 ④ 반영 비율(%)** 네 가지만 넣으면 됩니다.
   평가 유형, 기본 점수(최저점), 평가 기준, 평가 기간은 **더 보기**를 열어 필요할 때만 넣으세요.
4. 반영 비율 합이 100%가 아니면 노란 경고가 나옵니다 (저장은 됩니다).
5. (자세히 모드) 자주 쓰는 항목은 **🗂 보관**을 눌러 두면 다음 학기에 **보관함에서 추가**로 골라 씁니다.

**학기 중에 항목을 고칠 때**
- 만점을 바꾸면 "기존 점수를 비율대로 환산 / 그대로 유지" 중에서 고릅니다.
- 반영 비율을 바꾸면 총점이 바뀌는 학생 수를 먼저 보여 줍니다.
- 점수가 있는 항목은 지우기보다 **"사용 안 함"으로 숨기기**를 권합니다.
- 모든 변경은 **🕘 변경 이력**에 남습니다.

## 5. 규정 설정 확인하는 법
**설정 → 자세히 모드 켜기 → 규정 설정** (처음 화면의 "규정 확인" 안내에서도 갈 수 있어요). ⚠ **반드시 우리 학교 학업성적관리규정과 일치하는지 확인하세요.**

| 설정 | 기본값 | 설명 |
|---|---|---|
| 세특 최대 바이트 | 1,500바이트 (500자) | 학교생활기록부 기재요령 기준. 바뀌면 숫자만 고치세요 |
| 바이트 계산 | 한글 3, 영문·숫자·공백 1, 줄바꿈 2 | NEIS 계산 방식 |
| 결시 처리 | 인정결시 → 재평가 우선(불가 시 인정점), 미인정·미제출 → 기본 점수 | 사유별로 방법·인정점 비율 변경 가능. 질병 80%·그 외 100%는 **예시값** |
| 소수점 | 소수 1자리 반올림 | 반올림/버림/올림, 0~3자리 |
| 수행평가 최소 반영 비율 | (비움) | 입력하면 평가 계획이 이보다 낮을 때 경고 |

- 각 설정 옆 **기본값으로 되돌리기**로 언제든 되돌릴 수 있습니다.
- 매 학년도 처음에는 화면 위에 "올해 기재요령과 학교 규정을 확인하셨나요?" 안내가 뜹니다. 확인 후 [네, 확인했습니다]를 누르세요.

## 6. 학기말: 성적·세특·엑셀
### 성적표
**성적·세특 → 📊 성적표** → 학급 선택
- 항목별 점수와 **환산 총점** = Σ(항목 점수 ÷ 만점 × 반영 비율)
- 색 표시: ※주황 = 결시 처리 점수, 🔁노랑 = 재평가 대기, 빨강 = 미입력
- 학급 평균, 항목별 점수 분포 그래프

### 엑셀 내보내기 (NEIS 입력용)
성적표에서 **📤 엑셀 내보내기** → 범위(이 학급 / 학년 전체 / 학교급 전체 / 전 학년) → 열 순서 조정 → 파일 만들기.
학급마다 시트 하나, 번호순입니다. "결시 처리 표시" 열에 어떤 처리였는지 적혀 있습니다.

### 기존 엑셀 점수 가져오기
**📥 점수 가져오기**: 이 앱에서 내보낸 형식(시트 이름 "중1-3", `번호` 열, 항목 이름 열)을 쓰면 됩니다.
덮어쓰기 전에 확인을 묻고, 결시 처리된 칸은 기본적으로 건너뜁니다.

### 세특 초안
1. **🧩 문구 템플릿**: 평가 항목·수준(상/중/하)별로 문장을 한 줄에 하나씩 여러 개 적어 둡니다. `{항목}`은 항목 이름으로 바뀝니다.
2. **✍️ 세특** → 학급 → **✨ 빈 학생 초안 생성**: 점수 수준 + 관찰 메모 + 태그를 조합한 초안이 만들어집니다.
   같은 반 학생끼리 문장이 겹치지 않도록 표현을 골고루 씁니다.
3. 학생을 하나씩 눌러 **반드시 읽고 고치세요.** 글자 수·바이트·남은 바이트가 실시간으로 나오고, 넘으면 빨간색이 됩니다.
4. **📤 엑셀 내보내기**: 바이트를 넘은 학생이 있으면 먼저 알려 줍니다.

> 초안은 템플릿 조합일 뿐이며, 학생부에는 **교사가 관찰한 내용**을 기재해야 합니다.

## 7. 백업
**설정 → 백업·기기 옮기기 → ① 보내기**의 [💾 이 기기에 백업 파일 저장]

- 규정 설정, 평가 계획, 점수, 메모, 세특, 템플릿이 **파일 하나(.json)**에 모두 들어갑니다.
- **최소 일주일에 한 번** 하세요. 7일이 지나면 대시보드에 백업 알림이 뜹니다.
- 파일을 메신저·이메일로 옮긴다면 **"비밀번호로 암호화"**를 켜세요. (비밀번호를 잊으면 아무도 열 수 없습니다)
- 백업 파일과 엑셀 파일에는 학생 정보가 들어 있습니다. 개인 USB·개인 클라우드 등 안전한 곳에 보관하세요.

## 8. 기기 옮기기 (노트북 ↔ 휴대폰)
노트북과 휴대폰의 데이터는 **자동으로 맞춰지지 않습니다.** 기기를 바꿀 때마다 아래처럼 하세요.

1. 방금까지 쓴 기기: **설정 → 백업·기기 옮기기 → ① 보내기** → 비밀번호 정하기 → **📤 다른 기기로 보내기**
   - 휴대폰(삼성): 공유 창이 뜨면 **카카오톡 → 나와의 채팅**(또는 구글 드라이브)
   - 노트북: 파일이 다운로드 폴더에 저장됩니다 → 카카오톡 PC의 **나와의 채팅**으로 보내기
2. 다른 기기: 카카오톡에서 그 파일을 저장(다운로드)
3. 다른 기기: 같은 앱 주소 열기 → **② 받기 → 📥 받은 파일 고르기** → 비밀번호 → **이 파일로 바꾸기**
4. 받는 기기의 데이터가 받은 파일보다 **더 최근에 바뀌었으면 빨간색으로 경고**합니다. (최근 입력을 덮어쓰지 않도록)

두 기기에서 동시에 입력하면 서로 합쳐지지 않습니다. **한 번에 한 기기에서만** 입력하세요.

## 9. 학기 마감
**설정 → 학기 → 학기 마감**: 그 학기의 점수·계획·메모·세특이 **읽기 전용**이 됩니다. 조회와 엑셀 내보내기는 계속 됩니다.
실수로 마감했다면 [마감 해제]로 되돌릴 수 있습니다. 마감 전에 백업을 권합니다.

## 10. 자주 묻는 질문
**Q. 인터넷이 끊겼어요.**
처음 한 번 열어 둔 기기라면 그대로 쓰시면 됩니다. 모든 기능이 인터넷 없이 동작합니다.

**Q. 학생 정보가 밖으로 나가지 않나요?**
네. 앱에는 데이터를 외부로 보내는 기능이 없고, 외부 AI·분석 도구·외부 글꼴도 쓰지 않습니다.
단, **내려받은 백업·엑셀 파일**은 선생님이 직접 관리하셔야 합니다.
개인 기기에 학생 정보를 저장해도 되는지는 학교·교육청 지침을 확인하세요. 이름 없이 번호만으로도 모든 기능을 쓸 수 있습니다.

**Q. 데이터가 사라졌어요!**
브라우저의 "인터넷 사용 기록 삭제/쿠키 삭제"를 하면 지워질 수 있습니다. 백업 파일로 복원하세요.

**Q. 사용법을 다시 보고 싶어요.**
화면 오른쪽 위 ❓ 사용법 버튼, 또는 설정 → 사용법 모음.

**Q. 앱 잠금(PIN)은 어떻게 하나요?**
설정 → 백업·기기 옮기기 → 맨 아래 앱 잠금 → PIN 설정. 앱을 열 때마다 PIN을 묻고, 위쪽 🔒로 바로 잠글 수 있습니다.
PIN을 잊으면 데이터를 지우고 백업에서 복원해야 하니 백업을 꼭 해 두세요.

**Q. "새 버전이 준비되었습니다"가 떠요.**
입력을 마친 뒤 [업데이트]를 누르세요. 데이터는 그대로 남습니다.

**Q. 실수로 점수를 지웠어요.**
그 반·항목 점수 입력 화면에서 **↶ 되돌리기**를 누르세요 (앱을 닫기 전까지, 항목마다 최근 50번).

**Q. 반영 비율 합이 100%가 아니라고 노란색이 떠요.**
저장은 되지만 총점이 100점 만점이 아니게 됩니다. 평가 계획에서 비율을 확인하세요.

**Q. 세특 바이트는 정확한가요?**
한글 3, 영문·숫자·공백 1, 줄바꿈 2바이트로 계산합니다. “ ” · … 같은 특수문자는 넘치지 않도록 3바이트로 셉니다.
최종 확인은 NEIS에서 해 주세요.

## 11. 개발자용 안내
```bash
npm install
npm run dev      # 개발 서버
node scripts/capture-help.mjs   # (개발 서버를 켠 상태에서) 사용법 그림 public/help/*.jpg 다시 찍기

npm run build    # 정적 사이트 빌드 → dist/
```
- 기술: React + TypeScript + Vite, Tailwind CSS, Dexie(IndexedDB), SheetJS(xlsx), vite-plugin-pwa
- **배포**
  - GitHub Pages: `.github/workflows/deploy.yml` (저장소 Settings → Pages → Source: GitHub Actions)
  - Netlify: `netlify.toml` 포함 (저장소를 비공개로 둘 수 있음)
- **가짜 데이터**: 누구나 쓸 수 있는 **연습 모드**(별도 저장 공간 `music-teacher-app-practice`)로 바뀌었습니다. 진짜 데이터를 지우지 않습니다.
- **개발 도구**(전체 초기화 버튼): 개발 서버 또는 `VITE_SHOW_DEV_TOOLS=1` 빌드에서만 보입니다. 실제 사용 전에 `deploy.yml`의 해당 줄을 지우세요.
- 성적 계산: `src/lib/grading.ts` · 바이트: `src/lib/bytes.ts` · 세특 초안: `src/lib/seteuk.ts` · 백업: `src/lib/backup.ts`
